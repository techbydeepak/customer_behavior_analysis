# 🛒 Customer Shopping Behavior Analysis

## 📌 Project Overview
This project analyzes **customer shopping behavior** using transactional data from **3,900 customer purchases** across multiple product categories. The goal is to uncover meaningful insights into **customer spending patterns, product preferences, subscription behavior, and purchasing trends** to support better business decision-making.  :contentReference[oaicite:0]{index=0}

---

## 🎯 Objectives
- Analyze customer purchasing behavior
- Identify spending patterns across demographics
- Compare subscriber vs non-subscriber behavior
- Discover top-performing products and categories
- Perform SQL-based business analysis
- Build an interactive dashboard for business insights

---

## 📊 Dataset Information
- **Total Records:** 3,900  
- **Total Columns:** 18  
- **Missing Values:** 37 (Review Rating column)

### Key Features
- Customer Demographics (Age, Gender, Location)
- Purchase Details (Item Purchased, Category, Season, Color, Size)
- Shopping Behavior (Discount Applied, Previous Purchases, Review Rating)
- Subscription Status & Shipping Type  :contentReference[oaicite:1]{index=1}

## ⚙️ Data Preparation & Cleaning
The dataset was cleaned and transformed using Python:

✅ Handled missing values in the **Review Rating** column  
✅ Standardized column names into **snake_case**  
✅ Created new features such as:
- `age_group`
- `purchase_frequency_days`

✅ Removed redundant columns for better consistency  
✅ Loaded cleaned data into **PostgreSQL** for SQL analysis  :contentReference[oaicite:2]{index=2}

## 🔍 Business Analysis Using SQL
Several business-related queries were performed to gain insights:

### 1. Revenue by Gender
Compared total revenue generated by male and female customers.

### 2. High-Spending Discount Users
Identified customers who used discounts but still spent above average.

### 3. Top Rated Products
Found products with the highest average ratings.

### 4. Shipping Type Comparison
Compared purchase amounts between **Standard** and **Express Shipping**.

### 5. Subscribers vs Non-Subscribers
Analyzed spending behavior based on subscription status.

### 6. Customer Segmentation
Classified customers into:
- New Customers
- Returning Customers
- Loyal Customers

### 7. Revenue by Age Group
Calculated revenue contribution by age group.  :contentReference[oaicite:3]{index=3}
